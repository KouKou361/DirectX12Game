# DirectX12Game

DirectX 12 を用いて、描画・入力の基盤から自作したゲームエンジンです。
エンジン内部の仕組みを理解するための学習目的で、個人で開発しました。

- 開発期間：2023年〜2024年（【約6か月】）
- 開発人数：1人
- 開発環境：Visual Studio 【2022】 / C++ 【17】 / Windows

## 主な機能

- DirectX 12 による描画基盤
- カスケードシャドウマップによる影の描画
- ゲームパッド入力（PS4 コントローラー対応）
- ImGui によるデバッグ UI


## 操作方法

1. 起動するとタイトル画面が表示されます。
2. PS4 コントローラーの〇ボタンでゲームが開始されます。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `Source/` | 自作コード（ゲーム・エンジン部分） |
| `Lib/` | 自作コード（【ライブラリ部分の説明】） |
| `External/` | 外部ライブラリ（【ImGui など】） |
| `Data/` | モデル・テクスチャなどの素材 |

`Source/` と `Lib/` が自作のコードです。
`External/` と `Data/` には外部のライブラリ・素材を含みます。
